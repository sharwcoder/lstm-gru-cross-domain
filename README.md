# lstm-gru-cross-domain
Cross-domain comparison of LSTM and GRU for time series forecasting on traffic volume and river discharge data (Google Colab notebook).
# LSTM vs GRU: Cross-Domain Time Series Forecasting

Code for the paper "Cross-Domain Generalization of LSTM and GRU Networks:
A Comparative Study on Traffic and Hydrological Time Series Forecasting".

## Data
- Metro Interstate Traffic Volume (UCI Machine Learning Repository)
- Daily discharge, USGS station 01646500, Potomac River (2000-2023)

## How to run
1. Open the notebook in Google Colab.
2. Set Runtime > Change runtime type > T4 GPU.
3. Run all cells from top to bottom.
